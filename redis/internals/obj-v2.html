Redis · robj

robj：Redis 值的对象外壳

robj 统一表示 Redis 的值对象。它记录逻辑类型、底层编码、访问状态和引用计数；真正的数据放在 ptr 指向的位置或直接编码在其中。

PART 02 · 字段

四个字段分别回答四个问题

它是什么、怎么存、是否常用、数据在哪

对象层将命令语义和底层结构连接起来。

type

逻辑类型

String、List、Hash、Set、ZSet、Stream 等。

encoding

存储方式

例如 String 的 int/embstr/raw，Hash 的 listpack/HT。

lru

淘汰辅助信息

LRU/LFU 策略用它判断访问时间或频率。

refcount + ptr

生命周期与数据

引用为 0 时可释放；ptr 指向 SDS、dict、quicklist 等。
