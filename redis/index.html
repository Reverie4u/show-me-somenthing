PART 01 · 总览

先区分类型、编码和底层结构

三层不是一回事

类型是命令语义；编码是同一类型在不同大小下的存法；底层结构是具体的数据组织方式。

PART 03 · 扩展

三个常见能力复用已有类型

它们不是新的 Redis type

学习时把它们看成“针对特定数据形态的命令和编码”。

Bitmap

String 的位数组视图

适合大量布尔状态、活跃用户交并集。

HyperLogLog

String 的近似去重计数器

约 12 KB 估算大规模基数，误差约 0.81%。

GEO

ZSet 的地理位置视图

经纬度编码为 score，支持附近搜索。
