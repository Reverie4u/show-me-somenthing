PART 01 · 命令

String 能做什么

常用命令

命令层只关心“值”；编码选择由 Redis 在内部完成。

命令作用
SET k v写入值；可带 EX/PX 过期，NX/XX 条件写。
GET k读取值；不存在返回 nil。
APPEND k s把 s 接到值末尾，返回新字节长度。
INCR / DECR把合法整数加一或减一；不是数字会报错。
MGET / MSET一次读写多个 key，减少网络往返。

否 ↓
较长字符串
对象与 SDS 分开分配使用 raw，便于扩容。

PART 04 · 边界

两个容易混淆的点

key 不是 String 类型的 value

任何 Redis key 都是主键空间 dict 的成员，通常以 SDS 保存；它不随 value 的类型改变。

key

dict 的 key

LPUSH todos x 中的 todos 仍是 SDS，不是 List 对象的一部分。

value

带类型的 robj

这里才会是 String、List、Hash、Set、ZSet 或 Stream。

过期

key 级别

EXPIRE 作用于整个 key，不是 String 内容里的某个字节。
