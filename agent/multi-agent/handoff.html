PART 01 · 是什么

一个 Agent 委托给另一个

谁擅长谁来做

处理中遇到自己不擅长的领域，把对话/任务转交给更专业的 agent，交接后由对方继续。

Agent A
识别需求属于 B 的领域如客服转接销售。
↓
Handoff
把上下文交给 B连同必要信息一起移交。
↓
Agent B
继续处理并给出最终结果
PART 02 · 实现

模型决定何时交接

Handoff 是“工具”

OpenAI Agents SDK 把交接表示为工具：每个 agent 配置 handoffs，模型判断该交接时调用它。

最小交接
receptionist = Agent(handoffs=[sales_agent])
# 模型判断该转给销售时自动交接
出处：OpenAI Agents SDK 官方 Handoffs 文档：交接把上下文传给另一 agent，常用于不同 agent 各有专长。
PART 03 · 取舍

边界与循环

别来回踢皮球

交接要有明确边界与退出条件，否则 A→B→A 可能无限循环，或上下文被重复携带。

明确边界

谁负责什么

每个 agent 的职责与交接条件写清，模型才判断得准。

防循环

限制步数

限制最大交接次数，或让交接后原 agent 不再接管。
