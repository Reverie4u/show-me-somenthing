PART 01 · 一句话

Agent 是自主完成目标的系统

感知环境，作用于环境，按反馈继续

一句话概括综合了四个一手出处；确切表述见 PART 02 与 PART 06。

目标
用户给的是结果，不必指定每一步。
↓
Agent
感知 → 推理 → 行动 → 观察核心是“下一步能继续做”。
↓
结果
可检查的完成结果不是只说“完成了”。
PART 02 · 两条主线

教科书 vs 工业界

四份一手定义

经典 AI 与工业界 LLM Agent 表述不同，但没有冲突，只是侧重不同。

经典教科书 / 论文工业界官方文档
代表Russell & Norvig · Wooldridge & JenningsAnthropic · OpenAI
强调理性智能体、感知-行动循环LLM + 工具 + 反馈循环
视角环境交互与理性模型动态决策多步任务

Russell & Norvig

教科书 · 《AI: A Modern Approach》

“能通过传感器感知环境、通过执行器作用于环境的事物。”另按能力给出反射式、基于模型、基于目标、基于效用、学习型五类。

Wooldridge & Jennings

论文 · Intelligent Agents: Theory & Practice

“处于某环境、能自主行动以达成设计目标的计算机系统。”四属性：自主性、反应性、主动性、社会性。

Anthropic

官方文档 · Building Effective Agents

agentic systems 分两类：Workflow 走预定义代码路径；Agent 由 LLM 动态主导流程与工具使用。“本质是在反馈循环中用工具的 LLM。”

OpenAI

官方文档 · Agents SDK

“配置了 instructions、tools 和可选运行时行为（handoffs、guardrails、结构化输出）的 LLM。”工程上即会规划、调工具、协作、持状态完成多步任务的应用。

PART 03 · 四要素

不同定义里的共性

四个出处都指向这四点

去掉各自的术语，剩下的共同结构。

目标

为谁完成什么

Wooldridge 叫“设计目标”，OpenAI 叫“应用任务”。

感知与行动

与环境交互

Russell 叫“传感器/执行器”，Anthropic 叫“工具调用”。

自主性

无需逐步指挥

Wooldridge 列为第一属性，Anthropic 强调“动态主导”。

反馈循环

据结果调整

Anthropic 称“environmental feedback in a loop”。

PART 04 · 循环

靠循环完成，而不是一次回答

一个最小 Agent 循环

模型决定下一步，程序执行并把结果交回。

最小循环
收到目标
while 未完成 且 未超时:
  下一步 = LLM 依目标 + 已有结果决定
  结果 = 调用工具(下一步)
  把结果交回给 LLM
返回最终结果
四步：决定 → 执行 → 观察 → 再决定。观察来自环境（工具结果/代码执行），是 Anthropic 所说的“地面真值”。
1

决定

先查慢日志是否开启。

2

执行

调用 redis-cli SLOWLOG GET 10。

3

观察

看到 KEYS * 多次出现。

4

再决定

解释风险，建议用 SCAN。

PART 05 · 基本架构

一个 Agent 的四个核心组件

LLM、工具、记忆状态、规划

四类组件的框架可溯源到一手文档与教科书；具体实现细节标注为“工程视角”，不作一手结论。

LLM 核心

大脑 · 决策

OpenAI：Agent 是“配置了 instructions 的 LLM”。Anthropic：“LLM 动态主导自己的流程与工具使用”。职责：读入目标 + 当前状态，决定下一步。

工具系统

感知与作用环境

OpenAI / Anthropic：tools。Russell & Norvig：传感器 / 执行器。模型只输出“调哪个工具、什么参数”，真正执行的是程序；工具接口需精心文档化。

记忆 / 状态

保持上下文

OpenAI：context（传给每个 agent 与 tool 的依赖与状态）。Anthropic：LLM 增强含 memory。Russell：基于模型的智能体维护内部状态。

细分：短期记忆≈当前任务上下文（context window），长期记忆跨任务保存、常用向量检索存取。短期/长期之分源自认知科学（Atkinson-Shiffrin），LLM agent 侧一手代表为 MemGPT 与 Generative Agents（Park 等以 recency / relevance / importance 评分检索）；向量数据库仅是承载长期记忆的工程实现。

规划 / 决策

拆解目标

OpenAI：Agent 会 plan。Anthropic：工作流 + LLM 主导。Russell：基于目标 / 基于效用的智能体做目标与效用推理。

推理手段：CoT（Wei 等 2022，arXiv:2201.11903）让模型生成中间推理步骤；ToT（Yao 等 2023，arXiv:2305.10601）在每个决策节点展开多个分支再评估。二者均有明确一手论文，是规划环节的典型手段。

一手与演进的区分：LLM、工具、状态/记忆、规划这四类的框架可溯源到 OpenAI / Anthropic 文档与 Russell & Norvig 教科书。CoT、ToT、短期/长期记忆均为有一手论文支撑的手段或细分；向量数据库、记忆衰减则属工程实现或启发式，非一手定义的必要组成。
协同：四组件都服务于同一个循环——规划 → 决策 → 调用工具 → 结果入状态 → 再决策。
PART 06 · 区别

普通 LLM 和 Agent 的差别

模型负责决定，程序负责执行

Agent 以 LLM 为“大脑”，再加工具、循环和停止条件（OpenAI 的可选运行时行为）。

普通 LLMAgent
输入一个问题一个目标
输出一段文字文字 + 工具执行结果
下一步通常等用户再问据工具结果自己继续
边界不能直接影响外部系统权限内读写、调 API、执行命令
不要误解：Agent 不等于“永远正确”。它是能执行多步任务的系统；工具权限、验证与停止条件仍需设计。
