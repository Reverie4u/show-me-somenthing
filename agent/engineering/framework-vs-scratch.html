PART 01 · 区别

框架给什么

框架封装的是“工程”，不是“智能”

框架提供工具注册、路由、状态管理、多 agent 编排等；手搓则自己实现循环，依赖更少、更可控。

框架手搓
上手快，脚手架齐全慢，要自己写循环
依赖多少，可控
定制受框架约束可深度定制
PART 02 · 怎么选

快速 vs 可控

按场景选

快速原型、多 agent 协作、需要工具生态用框架；要最小依赖、深度定制、研究性实验用手搓。

用框架

省事

团队多人协作、标准工具、快速上线。

手搓

可控

最小依赖、精细控制每步、方便替换模型。

PART 03 · 结论

框架不加智能

先想清楚，再选工具

Anthropic 提醒：框架不会让 agent 更聪明；先想清楚要 workflow 还是 agent，再用框架承载设计。

出处：Anthropic《Building Effective Agents》：框架不够时，可以从一个简单循环开始，再补组件。
