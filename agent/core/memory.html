PART 01 · 为何

保持“做到哪了”

没有记忆，多步任务会迷路

上下文窗口有限，中间结果、工具返回、历史推理都占用空间；记忆负责保存并取回这些状态。

出处：LLM 上下文有限、Agent 需持状态完成多步工作，见 Anthropic《Building Effective Agents》与 OpenAI Agents 文档。
PART 02 · 分层

短期 vs 长期

两种记忆，两种粒度

短期 ≈ 当前任务上下文；长期跨任务保存，常用向量检索。

短期长期
范围当前任务上下文跨任务保存
载体context window向量库 / 摘要
问题窗口有限检索准确率
来源：短期/长期之分见 Atkinson-Shiffrin 认知模型；LLM agent 侧一手代表为 MemGPT 与 Generative Agents（以 recency / relevance / importance 检索）。向量数据库是工程实现，非一手定义。
PART 03 · 实现

检索与压缩

相关的才取回

长期记忆不可能全塞进上下文，只检索“当前相关”的部分；无用记忆要压缩或衰减。

检索

按需取用

嵌入 + 相似度，或按 recency / relevance / importance 打分。

压缩

控制体积

旧消息摘要、去重、衰减低频信息，避免撑爆上下文。
