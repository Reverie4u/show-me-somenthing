PART 01 · 作用

感知与作用环境

工具 = 传感器 + 执行器

Read 类工具感知外部，Write 类工具作用外部。

感知

读外部

搜索、查询、读文件；对应 Russell & Norvig 的传感器。

作用

写外部

调 API、执行命令、落盘；对应执行器。

出处：“传感器 / 执行器”见 Russell & Norvig《AI: A Modern Approach》；工业界以 tools 体现，见 OpenAI / Anthropic 文档。
PART 02 · 接口

函数签名

工具要能被模型“看懂”

把每个工具描述成清晰的函数签名：名称、作用、参数、返回。

最小工具定义
名称 search
描述 按关键词返回网页标题与摘要
参数 query: string
返回 list{title, url, snippet}
关键：参数与返回值越明确，模型选对工具、填对参数的概率越高。
PART 03 · 设计

文档与安全

权限与验证要设计

工具越多、权限越大，越需要边界：最小权限、参数校验、输出截断。

最小权限

只给必要

只暴露任务需要的工具，避免读到敏感数据或破坏环境。

参数校验

防止误用

执行前校验参数；返回/日志需截断，防止撑爆上下文。
