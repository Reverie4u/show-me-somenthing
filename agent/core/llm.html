PART 01 · 角色

决策中枢

读状态，出下一步

LLM 接收“目标 + 当前状态（历史、工具结果、记忆）”，输出下一步：再推理、调工具、还是给出最终答案。

输入
目标 + 当前状态包括上下文与记忆。
↓
LLM
决定下一步再推理 / 调工具 / 结束。
PART 02 · 定位

官方怎么定义

两种表述，同一核心

工业界把 Agent 的大脑说成配置好指令与工具的 LLM，或由 LLM 动态主导的循环。

表述
OpenAI“配置了 instructions、tools 和可选运行时行为的 LLM”，见 Agents SDK。
Anthropic由 LLM 动态主导流程与工具使用的 Agent，见 Building Effective Agents。
出处：OpenAI Agents SDK、Anthropic《Building Effective Agents》官方文档。
PART 03 · 边界

只决策，不执行

真正执行的是程序

LLM 只输出“选哪个工具、填什么参数”；读文件、调 API、跑命令由代码完成，结果再交回 LLM。

关键分工：模型负责决策、代码负责执行与回填，这也是 ReAct 实现的核心，见 ReAct。
