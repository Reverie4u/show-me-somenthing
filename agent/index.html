什么是 AI Agent

从「一句话定义」开始，理解 agent 与普通聊天机器人的差别，以及它靠什么循环完成任务。

PART 01 · 总览

Agent 是什么

会用工具完成目标的 AI

Agent 不只回答，还会根据结果决定下一步，直到完成或停下。

目标
用户给的是结果，不必指定每一步例如「整理下载目录，只保留 PDF」。
↓
Agent
拆步骤、选工具、看结果再调整核心是「下一步能继续做」。
↓
结果
可检查的产出 + 说明做了什么不是只说「完成」。
PART 02 · 核心

三个关键词

工具、循环、停止条件

这是 agent 区别于聊天机器人的骨架。

工具

能做什么

读文件、执行命令、搜索网页、调用 API。

循环

目标→决定→执行→观察

观察后的信息会直接影响下一次决定。

停止条件

何时结束

完成、失败、超时或达到最大步数。
